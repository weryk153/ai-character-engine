# VRM 0.x acceptance fixture

This directory contains **derived technical metadata only** from a third-party VRM 0.x model used for legacy VRM compatibility regression.

- Source SHA-256: `b5fffb730d99b27ffdd64f6c1f039f1b6c5c4cfaa502d474a90374b226b8b48e`
- Parsed VRM spec: `0.0` (`vrm0` compatibility family)
- Raw `.vrm` / `.vrma` bytes are intentionally **not** included in this repository or release archive.
- The source model metadata reports redistribution prohibited, so the acceptance fixture is limited to manifest/calibration/report JSON generated by the engine.

The fixture proves that the normalized engine vocabulary can target a real legacy model without requiring the raw third-party asset in automated regression tests.
